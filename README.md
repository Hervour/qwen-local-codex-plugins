# Qwen Local Codex Plugins

Local-first Codex plugins for Qwen image generation/editing and local vision analysis.

## Plugins

- `qwen-local-image-plugin`: Qwen-Image 2.1 workflows for text-to-image, image editing, and manga storyboard-to-page generation through ComfyUI.
- `qwen-local-vision-plugin`: local Ollama vision or OpenAI-compatible VLM bridge for describing local images and OCR.

`qwen-test-images` contains small smoke-test outputs only.
